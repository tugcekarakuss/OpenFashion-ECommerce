# OpenFashion

A modern eCommerce web application built with React and Tailwind CSS.

This project is based on the Open Fashion UI Kit and focuses on building a clean, responsive, and component-driven frontend experience.
 
 ![OpenFashion Preview](project-preview.jpg)

Project is currently in development. Features like product listing, cart, and detailed product pages are being implemented.

## Tech Stack
- React
- Tailwind CSS
